Blog posts go in this folder as Markdown files, one per post. The file name becomes the URL,
e.g. learning-mechanics-intro.md -> /blog/learning-mechanics-intro/

Each post starts with front matter:

---
title: An introduction to learning mechanics
date: 2026-11-01
authors: [Jamie Simon, Daniel Kunin]
summary: One or two sentences shown on the blog listing.
draft: false   # true hides the post from the site
---

Then the post body in Markdown.

(This file ends in .txt so it isn't picked up as a post.)
